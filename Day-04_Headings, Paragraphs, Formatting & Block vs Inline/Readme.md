# What is Tag & Element ?

## Tag
~~~
<keyword>  this our tag basically in our lower than sign and greater than sign in those between we write some keyword those are Tags. and these are tell to browser what type in this Content.
~~~
We have two type of Tag
first we have Opening Tag and
Second we have Closing Tag
~~~
- Opening Tag --> <H1>
- Closing Tag --> </h1>
These are in Pair like 
 <h1>These our Content </h1> and in those between we write our Content that was showing in User
~~~

## Self Closing Tag (Void Element)
~~~
<meta>
<img>
<br>
these tag have no closing tag and no content
~~~

## Element
In our opening Tag and closing tag and our content those three are give our element.
~~~
<h1>This is Our Element </h1> 
~~~

## Attributes
Attributes are for giving our element to Extra information. 
~~~
<h1 title="this is our element">This is Our Element </h1> In this title are our attributes
~~~
## Heading Tag
Heading tag for Showing Our content important and large and big & Black 

we have Six level of heading Tag an each of our tag will be small.
~~~
<h1> => This is Big Heading 1
<h2> => This is Subheading 2
<h3> => This is Heading 3
<h4> => This is Heading 4 
<h5> => This is Heading 5
<h6> => This is Heading 6
~~~

## Paragraph Tag
Paragraph tag is for writing a Paragraph or normal text in our webpage.
~~~
<p>This is Our Paragrpah </p>
~~~

## Text Formatting
A Normal Text format like Some Bold and Italic or large this is Text Formatting
Eg;-
~~~
<b>Hello this is Bold Tag</b>
<br> for Linebreak
<strong>Hello this is Strong Tag</strong>
~~~

## DIV, Span & Block Vs Inine

### Block
Block is our Display Properties.
this take our full Width of line and other content showing in next line 

### InLine
in this element we write another element in same line
An Inline element does not start on a new line
An inline element only takes up as much width as necessary. 

### Div, Span
Div is a container its contain our all element. this is Block tag

### Span
