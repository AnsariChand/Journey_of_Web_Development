**1. Topic Introduction**

### 1. What is Css Display?

*Display* property tells the browsers how element page layout behave on the page. 
```
.box {
    display: block;
}
,
.box {
    display: inline;
}
```

Real-world analogy:

**Imagine One Classroom**

- block --> Student Sit on full Bench / full line Occupies.
- inline --> Student existing line mein hi khada hai.
- inline-block --> same line mein hai, lekin uske pass proper box size hai.
- none- --> student classroom mein hain hi nahi.

### 2. What is CSS Position ?
**Position** property decide karti hai ki element page par kis positioning system ke according place hoga.
