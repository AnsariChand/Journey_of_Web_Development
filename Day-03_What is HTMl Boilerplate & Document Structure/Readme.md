 ## Head Sections
 Head Sections this information is not appear in our webpage but for browser/search engines very important.

- meta charset= "UTF-8"
this will tells the browser which character encoding we uses.
UTF-8 almost universal and this will supports emojis, special characters 
(₹, é, अ),

- meta name="viewport" content="width=device-width, initial-scale=1.0"
this one line for mobile responsiveness foundation.
Breakdown:
width=device-width :- Page width set to device screen width 
initial-scale=1.0- zoom level 1 (no zoom)
