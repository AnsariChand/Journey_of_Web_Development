# Anchor Tag

Anchor Tag - This html tag makes links Clickable.

## Attribute

href --> Hypertext REFerence --> this attributes tell where link goes

h means --> hypertext
ref --> reference

this attribute was very important for Anchor Tag

```
<a href="https://youtube.com" target="blank"> Click here</a>
```

Target blank will be open webpage in the new Tab

HTML ka sabse versatile tag hai - yeh ek hi
tag hai, lekin type attribute change karke yeh bilkul
alag field ban jaata hai

```
<input type="number">

<input type="Text">

<input type="password">

```
